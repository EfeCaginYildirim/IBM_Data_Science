# IBM Data Science Professional Certificate — Coursework

Hands-on labs, practice projects and graded assignments I completed for the
[IBM Data Science Professional Certificate](https://www.coursera.org/professional-certificates/ibm-data-science) on Coursera.

**Certificate:** [verify on Coursera](https://www.coursera.org/account/accomplishments/professional-cert/PTRTL7GBN782)
